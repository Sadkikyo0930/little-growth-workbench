# 小小赛车成长工坊 V6 — PWA 桌面版

## iPhone 安装步骤
1. 用 **Safari** 打开 https://sadkikyo0930.github.io/little-growth-workbench/v6/
2. 安装前，在 **成长中心 → 导出完整学习档案** 保存 JSON 文件到 iPhone「文件」。
3. 在 Safari 的页面菜单中选择「分享」→「添加到主屏幕」。
4. 打开 **作为网页 App 打开**（如出现该选项），点击「添加」。
5. 从主屏幕打开「赛车成长」，在 **成长中心 → 从备份恢复** 导入先前保存的 JSON 文件。
6. 再次进入测评、课程和成长中心确认数据。

## 资料安全
- 不会自动清空数据，不修改其他版本的本地存储。
- Safari 与主屏幕 App 可能使用不同的存储空间。为了不丢失之前的语文成绩，务必先备份再导入。
- 完整备份覆盖 `growth-workbench-v6-adaptive-2` 主记录，以及 `v6_` 或 `v6-` 开头的课程进度键。
- 备份/导入只在使用者点击按钮后执行；导入会先请求确认并自动保存被覆盖前的备份。
- PWA 仍为**本地存储**，没有云端账号同步。请定期导出备份。

## 离线与更新
- 第一次安装或访问需要联网。
- 缓存范围仅 `/little-growth-workbench/v6/`；不会清理 V5 或其它项目。
- 已缓存页面可离线使用；部分课程图片、音频、云端语音服务或未曾访问的内容仍可能需要网络。
- 再次联网打开页面会优先拉取网页最新版；静态资源可能下一次启动才更新。
- 验证环境：尚未完成真实 iPhone Safari / 桌面版离线及语音测试。
