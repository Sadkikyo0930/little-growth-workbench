# R5 独立测试家庭：边界与安全清理

## 当前状态

这是同一个 CloudBase 环境内按家庭ID和数据库RLS隔离的测试入口，不是新建云环境。正式 V6 `/v6/` 保持原文件；测试 V6 使用 `/v6-selftest/`。两者同属 GitHub Pages 域名，所以测试页额外隔离浏览器存储，不能把仅换URL称为隔离。

- 测试家庭固定 `r5-selftest-family`，忽略URL中的家庭覆盖参数。
- 所有测试页面/课件先加载 isolation.js。localStorage/sessionStorage/IndexedDB 使用 `r5-selftest.v1:` 前缀。无正式本地成绩、登录和游戏令牌导入/清除。
- 测试页不注册Service Worker；原正式Service Worker不注销、不清缓存。
- 旧 family-auto-sync 在测试副本中禁用；只有受保护的R5桥接器可写当天答题。
- 数据库写入只允许测试家庭的当天R5计划、成绩、新设备绑定。请求边界拒绝其他家庭、UPDATE/DELETE以及成员迁移。最终授权仍由已部署的数据库RLS/成员函数决定。
- 每次同步先核对当前登录 UID 唯一属于测试家庭且为 owner/parent；正式账号/多家庭账号/未授权账号停止。
- 当天发现预置80%演示数据或其他账号成绩即停止，不能冒充真实答题结果。
- 设备由通过检查的测试账号在页面点击后以随机新令牌建立，绑定请求只指定测试家庭；不会复用或搬迁既有正式设备。公开demo设备不能用于此入口。
- 2026-11-09课程起点不改；开课前不发布计划、不上传成绩。计划日/科目冲突仍停止。当前没有管理员凭证或独立测试账号登录会话，不能声称真实账号/RLS正向写入已验收。

## 开始前

先打开 family-sync.html，仅在此输入独立测试账号密码，密码不会保存或提交GitHub。只读检查必须通过，且无当天演示成绩污染，再新建本次测试设备。页面在实际开课日后才显示答题链接。未通过时不要开始答题，勿改用正式账号绕过。

如果账号尚未属于测试家庭，需由现有管理员核对真实认证UID并只新增该测试家庭的成员关系。这不是前端修改能替代的步骤。入口不会自行建账号、迁移成员、扩大RLS或运行迁移。

## 安全清理方案（本次不执行云端删除）

1. 先停止测试赛车会话，仅对测试家庭发stop；导出本次真实答题验收证据。
2. 记录本次独立测试UID、当前日期、实际新增record_id清单、本次新建测试设备标识。不要在GitHub上传令牌/密码。
3. 由管理员只读预览：`growth_learning_records` 必须同时满足 `family_id='r5-selftest-family'`、`created_by=本次测试UID`、`record_id` 属于确认清单。确认行数后才进入事务。
4. 仅删除上述精确记录，使用 `DELETE ... RETURNING record_id` 对照清单；不使用前缀通配删除、不TRUNCATE、不删正式家庭任何行。普通登录账号禁止DELETE是正常保护，不要为清理修改RLS/权限。
5. `r5_daily_plan`、`r5_daily_usage` 以家庭+日期聚合，无法仅靠UID隔离同一天其他测试。只有确认当天测试家庭独占、无活动会话、留好快照后，才可单独审核本次日期的计划/usage；否则保留。不得改正式日期或提前重置计时来通过测试。
6. 本次新建测试设备如需撤销，先核实其family_id确为测试家庭且在本次清单，再以测试parent调用 `r5_revoke_device`；不要使用既有真实设备令牌。保留审计，不批量删device/member/family/settings。
7. 预置演示数据使用独立审核清单（原seed脚本的22个record_id及created_by=r5-selftest-parent），不得和真实答题记录混删。当前演示数据没有自动清理；不能用它证明真实答题成功。
8. 页面“仅清理本机测试数据”只处理 `r5-selftest.v1:` 命名空间；正式浏览器存档、家庭历史和设备绑定不动。仅本机清理不等于云端清理。

清理SQL属于未来、经人工核对后的数据DML，不是迁移。本次未执行任何数据库迁移、腾讯SQL或云端删除，也不重建服务。
